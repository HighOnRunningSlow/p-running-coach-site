Garmin data. Training context.

Your training, connected.

P Running Coach brings Garmin activities and available daily wellness measurements into Google Sheets, with optional original FIT files in Google Drive.

See running progress alongside workload from other sports, stress, heart rate and sleep—all in a structured training database.

Explore the application

From activity to context

  1. Garmin ConnectActivities and available wellness data from the official Personal API.
  2. Google SheetsOrganized records, laps, summaries and training-plan actuals.
  3. Google DriveOptional storage for supported original FIT files.

A fuller training picture

Running progress, with the rest of life in view.

The application organizes recorded measurements and clearly labelled calculations. Availability depends on what Garmin returns for each activity and date.

Activities across sports

Import available activities across sports, including multisport child activities. Track distance, duration, elevation, heart rate, power and training metrics where supplied.

Daily wellness context

Review available stress, resting heart rate, HRV, sleep stages and scores, Body Battery, steps, energy, respiration, SpO₂, hydration and weight measurements.

Laps and effort analysis

Parse supported FIT files for laps and intervals. For eligible running records, calculate labelled sustained-effort and heart-rate drift estimates.

Weekly summaries

Keep running mileage and performance trends separate from all-sports workload. Coverage indicators show when training-load information is incomplete.

Plans and race goals

Maintain planned sessions and race targets in the spreadsheet. Link completed activities to fill actual distance, pace and training load while preserving planned-session fields.

Historical imports

Import accessible activity history in resumable batches. Synchronization records and FIT status fields identify progress, unsupported originals and missing enrichment.

Cloud operation

A training database that updates without your desktop.

Scheduled GitHub Actions runs retrieve Garmin data and update a configured Google spreadsheet. When enabled, frequent checks target every 15 minutes, with daily reconciliation for a wider recent-data window.

An unchanged normal check makes no Google Sheets writes and adds no Sync Log row. Checks that find changes publish the corresponding updates. Initialization and historical maintenance are separate operations.

Scheduling is best effort: GitHub delays, API limits and the time taken for a device to sync to Garmin can affect freshness.

Built for review and coaching conversations

Use the spreadsheet directly, or choose to make it available through an existing ChatGPT Google Drive connection for interactive analysis.

The synchronization pipeline does not call an OpenAI API, run a chatbot or automatically generate a training plan. Any ChatGPT access is a separate connection you control.

Blank fields mean unavailable data, not zero. Calculated estimates are distinct from Garmin measurements. This is training context, not medical diagnosis.

Understand the connection.

This website explains the application and requires no sign-in. It does not connect your Garmin or Google account. Running the application requires separate credential setup and Google authorization.
